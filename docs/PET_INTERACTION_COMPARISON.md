参考 [OpenAI 官方 Pets 说明](https://learn.chatgpt.com/docs/pets)。官方文档没有公开逐帧动画调度源码，因此不能据此声称复制了 Codex 的动作算法。

| 可参考的功能 | MajdataAlpha 当前情况 | 尚缺的部分 |
| --- | --- | --- |
| 拖动悬浮桌宠 | 已有拖动、工具栏吸附、拖出、启动跳出 | 启动位置固定在任务栏上方，还没有独立记忆悬浮位置 |
| 反映软件工作状态 | 已有初始、写谱、语法错误、预览四态 | 多 Edit 共用时，目前不是每个 Edit 各自显示状态的托盘 |

默认桌宠为迪拉熊。加载素材时跳过透明帧；缺失的行走动作复用已有写谱动作，缺失的朝向使用待机静帧。写谱和语法错误动作完整播放一次，结束后安静待机 20–35 秒；预览动作间隔 18–29 秒。冷却按状态分别记录，重复通知和拖动结束不会重启动作，切换状态也先播放完当前动作。保留状态去抖、防止鼠标视线打断错误动画及回调互相覆盖的修复；不重新加入曾造成闪烁的图像交叉淡化。

接下来适合先做位置记忆、统一隐藏/唤回，以及桌宠旁紧凑的 Edit 状态列表。屏幕 Appshots、聊天/语音入口属于 Codex 的业务能力，不应生搬到写谱工具中。

身体持续缓慢呼吸，脚底固定；高度在 100%～105%、宽度在 100%～101.2% 之间变化，完整周期约 4.2 秒。左键点击时短暂压下并回弹，叠加在呼吸上，不替换当前动作。
