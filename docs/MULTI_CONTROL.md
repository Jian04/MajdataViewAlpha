# 多窗口控制与合成录制

从 Edit 的「联机 → 多窗口控制台」打开侧栏标签。普通启动的 Edit 自动分配独立组号，控制台自动发现各组；每组打开歌曲，配套 View 必须由当前 Alpha Unity 源码构建。

- 勾选 01、02 等窗口，统一播放、暂停、停止或按秒跳转。全部 View 准备完成后使用共同开始时间。
- 黑色画布就是合成视频范围。拖动色块安排位置，点击后输入各自宽高，不要求相同长宽比。「横向排列」紧密相邻并调整画布；也可网格排列。
- 「应用布局」移动实际 View 窗口。「保存布局」按组号保留位置与尺寸。
- 「开始统一录制」先生成各组音频，再共同录制，结束后按开始时的画布快照合成为 out_multi.mp4。混合所有窗口音轨并归一化，保留各自打击音。同一目录只保存一份成片，完成后打开文件所在位置。
- 录制期间保留各个 View 的位置，结束后恢复各自原来的大小与位置。
- 「依次导出」按列表顺序逐个录制，保存为对应歌曲目录中的 out_01.mp4、out_02.mp4 等。
- 「停止全部」取消准备或录制。关闭控制台标签取消当前批次；切换标签或收起侧栏继续任务。

画布宽高为 256–16384 的偶数，每个 View 的录制尺寸为 256–3840 的偶数。片头、曲卡和 AP 表现沿用各 Edit 设置。时长不同时，结束区域保持黑色至最长视频结束。

Tests/MultiControlRegression 检查准备屏障、失败回滚、取消、共同开始时间和独立输出。传入 --ffmpeg Assets/StreamingAssets/ffmpeg.exe 可实际编码测试不同长宽比与紧密拼接的像素位置。完整多 View 渲染仍应使用最新 Unity 构建验收。
