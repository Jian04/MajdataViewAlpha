# 独立 Edit + View 实例

普通启动的 Edit 自动创建独立组合，也可在「联机」或桌宠菜单新建组合。每个 Edit 分别打开歌曲；必须配套当前 Alpha Unity 源码构建的 View。

- Edit 和 View 使用相同的 01、02 等编号与颜色，View 标识在录制时隐藏。
- 实例列表显示编号和进程状态，端口放在提示中。可定位窗口或请求关闭组合，关闭走正常保存提示。
- 自动从 18013 起分配端口，跳过已登记组和占用端口。普通控制仅监听本机，开房才开启局域网服务。
- 录制临时文件、日志、管道、预览、曲卡缓存及自动保存按组隔离。活动组通过 PID 与进程启动时间校验。
- 单纯打开同一 TXT 不会自动联机；请加入同一房间。保存检测外部修改，冲突时保留本地稿。

参见 [联机写谱](COLLABORATION.md)、[合成录制](MULTI_CONTROL.md)、[工具侧栏](TOOL_SIDEBAR.md)。Tests/SessionRegression 覆盖六进程并发端口分配、占用跳过、配套通信与进程身份。完整多 View 播放和录制应使用最新 Unity 构建验收。
