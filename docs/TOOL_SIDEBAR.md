# 工具侧栏

录制、Alpha 语法帮助、编辑器设置、音量、歌曲信息、谱面库、分析检查、多窗口管理和联机页面在 Edit 右侧以标签呈现。

- 点击对应菜单时打开或切回标签，平时不占空间。
- Edit 默认宽度为 800，最小宽度 600；侧栏默认宽度 340，在窗口内占位，开关不改变窗口大小或位置。
- 点击窗口最右侧的侧栏图标或按 `Ctrl+Alt+B` 显示／隐藏；隐藏保留页面状态和后台任务。
- 点击标签切换，点击 × 关闭。最后一个标签关闭后自动收起侧栏。
- 拖动编辑区与侧栏之间的分隔条调整宽度。
- 录制和多窗口页使用外侧整页滚动，按钮与单行输入框统一为 30 高、13 号字体。
- 关闭设置页沿用设置保存逻辑；关闭联机页断开房间，关闭录制管理页取消当前批次。

文件选择、保存确认等短暂对话框仍使用系统窗口。
