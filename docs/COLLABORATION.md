# 联机写谱

1. 在「联机」侧栏填写自己的名字；名字保存在本地，之后继续使用。
2. 房主设置房间名称，可勾选设置密码，然后创建公网房间。软件自动建立连接，不需要另装或登录组网软件。
3. 成员在大厅搜索并加入，也可以填写房主分享的公网地址。素材同步完成后自动切换到房主的歌曲与难度。
4. 只同步 `maidata.txt`、`track.mp3/ogg`、`bg.png/jpg` 和可选的 `pv.mp4`。音频与封面先传，视频在加入后继续传；录制输出和缓存不传。下载缓存位于 `%LOCALAPPDATA%\MajdataAlpha\RoomSongs`。
5. 文字与光标实时共享。房主保存沿用原歌曲保存逻辑；成员保存自己的 TXT。成员断开时可以选择保存，加入时不用指定空文件夹。

真正重叠的修改或过旧版本不会直接覆盖：保留本地稿并提示冲突，可备份后载入最新版进行合并。临时网络错误自动重试。远端更新清空旧撤销记录，避免撤销覆盖其他人的修改。同步不等于磁盘保存，房主应及时保存。

新版房主连续推送素材，不再每 32 KB 等待一次网络往返；进度按 0.1 MB 更新。中断后尝试从已有片段继续，完成后校验 SHA-256。连接旧版房主时回退到旧分块协议，因此双方更新后才能使用连续传输。

当前使用自动公网隧道，优先 Cloudflare，建立失败时尝试备用线路；尚未实现 P2P。速度仍受双方网络和公网线路影响。

`Tests/CollaborationRegression` 覆盖实际 TCP/WebSocket 连接、并发合并、身份校验、光标、歌曲切换、连续传输、非块对齐的断点续传及取消。`--internet-probe` 使用随机文件验证真实公网音频与视频传输，不上传用户歌曲。
