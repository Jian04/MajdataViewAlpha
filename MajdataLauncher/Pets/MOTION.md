# 桌宠动作配置

每个桌宠使用自己目录下的 `motion.json`。所有动作配置和开关仅在此文件中修改；修改后重新启动桌宠或切换到该桌宠生效。

| 字段 | 意义 |
| --- | --- |
| `breathingIntervalSeconds` | 两次呼吸之间的等待时间，秒；等待时保持原形 |
| `breathingDownSeconds` | 一次呼吸向下压扁的时间，秒 |
| `breathingUpSeconds` | 一次呼吸向上弹起并回到原形的时间，秒 |
| `elasticityEnabled` | 呼吸及点击形变开关，默认 `true` |
| `dragGravityEnabled` | 左右拖动的惯性倾斜及松手回摆开关，默认 `true` |
| `clickExpressionCooldownSeconds` | 点击表情的独立冷却时间，秒；与写谱、错误、预览动作冷却分开 |

一次循环的总时间为间隔、下压和上弹三个时间相加。迪拉熊和 Uni 均为间隔 0 秒、下压 1.96 秒、上弹 2.24 秒，共 4.2 秒；高度 97%～105%，宽度反向轻微变化，脚底固定。两个桌宠的点击表情冷却默认均为 6 秒。

旧配置在加载时自动换算并写回新配置，移除旧的速度和周期字段，其他设置保留。原来的下压时间换算为下压时间，弹起与回落时间之和换算为上弹时间，间隔为 0 秒。Uni 已换算为间隔 0 秒、下压 1.96 秒、上弹 2.24 秒，动作和 4.2 秒周期保持不变。新配置未填写的时间分别取 1.4、0.4、0.4 秒。

点击形变使用独立的短反馈动画，只在左键松开且未拖动时触发；按住、拖动和拖动松手均不触发点击形变。

拖动惯性根据加速和减速产生：加速时身体向后倾，急停时向前回摆，再阻尼恢复直立；匀速拖动不会一直向同一边倾斜。加速度作用倍率为原来的两倍，最大倾角 35°。拖动位置和倾斜逐帧同步更新，停靠探测在后台运行。点击拍打保留当前气泡及其剩余显示时间。
